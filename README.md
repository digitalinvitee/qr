LIVE DRIVE VERSION

The landing page is connected to the provided Google Apps Script Web App URL.
Uploads are sent one file at a time to the Apps Script endpoint.

Before using the QR at the event:
1. Host these files on HTTPS (for example GitHub Pages).
2. Test with one small photo from a phone.
3. Confirm that the photo appears in the target Google Drive folder.
4. Only then test larger photos/videos and publish the final QR.

Target Drive folder is configured in Code.gs, not in this frontend.
